# Offline Spotify (MP4 Edition)
# instructions.txt

==========================================================
PROJECT GOAL
==========================================================

Build a desktop application that looks almost identical to Spotify but works completely offline.

The application will play ONLY local MP4 files stored inside a folder named `songs`.

The UI must match the design provided in `index.html`.

Do NOT redesign the interface.

==========================================================
READ FIRST
==========================================================

Before writing ANY code:

1. Read index.html completely.
2. Read this instructions.txt completely.
3. Inspect the current project.
4. Explain your implementation plan briefly.
5. Only then begin coding.

Never skip these steps.

==========================================================
SUPPORTED FILES
==========================================================

Only support:

.mp4

Ignore every other file type.

==========================================================
SONGS FOLDER
==========================================================

Create a folder named

songs

The user will place MP4 files into this folder.

Every time the application starts it must

• scan the songs folder
• detect new videos
• remove deleted videos
• update library.json automatically

No manual refresh button.

==========================================================
LIBRARY
==========================================================

Maintain

library.json

This file stores information about every discovered MP4.

Example fields

id

filename

title

path

duration

thumbnail

favorite

playCount

lastPlayed

The application should automatically synchronize this file every startup.
